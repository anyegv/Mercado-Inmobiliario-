# Journal: Bitácora del Proyecto
**Mercado Inmobiliario en Cuba**

## Fase 1: Ideación y Planteamiento
**Inicios de octubre**
El primer paso no fue programar, sino sentarme a pensar. Empecé recolectando ideas y haciéndome preguntas en base al tema central del mercado inmobiliario. Hice una lluvia de ideas inicial y, tras una limpieza y filtrado, seleccioné las preguntas que realmente valía la pena responder con los datos a mi alcance. Una vez tuve claros mis primeros pasos y objetivos, comenzó el trabajo de campo.

## Fase 2: Recolección y Estructuración de Datos
**A partir del 3 de octubre**
Con las preguntas claras, empecé a buscar los datos que me permitieran responderlas (Casa Oasis, Revolico, etc.). En paralelo, fui confeccionando los archivos JSON (`Alquileres`, `Casas x Cuarto`, `Alquileres x Zona`). Esto fue clave: a medida que extraía la información, la guardaba y organizaba de forma estructurada para que el código pudiera procesarla después sin problemas.

## Fase 3: Desarrollo del Código
**Mediados de octubre**
Una vez tuve los datos extraídos y listos en los JSON, comencé a programar. El primer paso fue crear un archivo (`Funciones.py`) para codear todas las funciones lógicas que sabía que necesitaría más tarde (limpieza, extracción de precios, etc.). Una vez tuve esa base sólida, creé el archivo de visualizaciones (`Graficas.py`) para empezar a construir las gráficas.

La organización del código fue uno de los mayores retos. Asegurarme de que cada función estuviera donde debía y que los módulos se comunicaran correctamente me costó tiempo y esfuerzo, pero fue fundamental para el éxito del flujo de trabajo.

## Fase 4: Obstáculos y Decisiones de Diseño
A mitad del proceso me topé con un muro: la falta de datos. Por distintas razones, varias preguntas interesantes que me había planteado al inicio se volvieron imposibles de responder (falta de fuentes oficiales, datos privados del MINJUS, etc.). Tuve que guardar y dejar de lado esos análisis. Fue frustrante, pero como aún conservaba un núcleo fuerte de preguntas viables, decidí seguir adelante sin que esto afectara el proyecto.

En cuanto al aspecto visual, tomé una decisión temprana: quería que todas las gráficas fueran visualmente entendibles. Por eso, establecí un patrón visual definido (misma paleta, misma tipografía, mismo estilo) para que el proyecto final se viera cohesionado y profesional.

## Fase 5: Resultado Final
Al final, me siento muy conforme con el resultado. Ver el proyecto terminado, con sus JSONs estructurados, el código organizado, las gráficas claras y los análisis correspondientes, justifica todo el esfuerzo. El proyecto cumple con su objetivo y queda listo para su revisión y despliegue.
